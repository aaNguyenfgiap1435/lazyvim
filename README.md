# LazyVim trên máy này

Cấu hình này dựa trên [LazyVim Starter](https://github.com/LazyVim/starter), theo [hướng dẫn cài đặt chính thức](https://www.lazyvim.org/installation). Bản cấu hình nằm tại `/home/linh/work/lazyvim`; `~/.config/nvim` là liên kết tới thư mục đó. Mở `nvim` ở bất kỳ thư mục dự án nào để sử dụng.

Xem [USAGE.md](USAGE.md) để bắt đầu, tra cứu phím tắt và xử lý sự cố.
